# Apple Maps tap-list — add these to a Guide

Apple Maps has **no bulk import** — no GPX, KML, CSV, or API. Guides must be
populated by hand. This is the whole set in add-order.

**How:** Apple Maps → Library / Guides → **New Guide**, name it *Beijing*.
Then tap each link below → **Add to Guide**. Two minutes for all twelve.

## Guide names worth splitting

Guides sync over iCloud and work offline once the places are cached. Worth
doing on wifi before you need them.

## The one that's time-critical

Row 12. 中秋节 (Zhōngqiūjié) is **25–27 September** and the mooncakes want to
be handed over *before* the 25th.
